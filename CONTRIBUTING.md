# Contributing to Hello

## Welcome!
Thanks for your interest in contributing to Hello!

## Code of Conduct
Please read our [Code of Conduct](CODE_OF_CONDUCT.md) first.

## How to Contribute

### Reporting Bugs
1. Check existing issues
2. Create new issue with template
3. Include reproduction steps
4. Add relevant labels

### Suggesting Features
1. Check existing feature requests
2. Create new issue describing feature
3. Explain use case and benefits

### Pull Requests
1. Fork the repository
2. Create feature branch: `git checkout -b feat/amazing-feature`
3. Make your changes
4. Write/update tests
5. Run tests: `npm test`
6. Commit: `git commit -m "feat: add amazing feature"`
7. Push: `git push origin feat/amazing-feature`
8. Open Pull Request

## Development Setup
See [Environment Setup](docs/onboarding/ENVIRONMENT_SETUP.md)

## Commit Convention
We use [Conventional Commits](https://www.conventionalcommits.org/):
- `feat:` New feature
- `fix:` Bug fix
- `docs:` Documentation
- `style:` Formatting
- `refactor:` Code restructuring
- `test:` Tests
- `chore:` Maintenance

## Code Style
- Use Prettier for formatting
- Follow ESLint rules
- Write meaningful comments
- Add JSDoc for public APIs

## Testing
- Write tests for new features
- Maintain > 80% coverage
- Run full test suite before PR

## Review Process
1. Automated checks must pass
2. At least one approval required
3. Address review comments
4. Squash and merge
