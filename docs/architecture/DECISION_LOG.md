# Architecture Decision Log

## ADR-001: Use React with TypeScript
**Date:** 2024-01-01  
**Status:** Accepted  
**Context:** Need to choose frontend framework  
**Decision:** Use React with TypeScript  
**Consequences:** Better type safety, larger ecosystem

## ADR-002: Use Supabase for Backend
**Date:** 2024-01-02  
**Status:** Accepted  
**Context:** Need scalable backend solution  
**Decision:** Use Supabase (PostgreSQL + Auth + Storage)  
**Consequences:** Faster development, managed infrastructure

## ADR-003: Use Vite for Build Tool
**Date:** 2024-01-03  
**Status:** Accepted  
**Context:** Need fast build tool  
**Decision:** Use Vite instead of Webpack  
**Consequences:** Faster dev server, better DX
